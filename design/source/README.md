# Исходные материалы компании

Здесь хранить предоставленные оригиналы: логотип, фотографии, материалы продукции и разрешённые к хранению знаки стандартов. Оригиналы не перезаписывать; обработанные версии — в `design/exports/`.

Для материала указывать происхождение, дату получения, назначение и ограничения публикации. Закрытые документы, секреты, заявки и персональные данные в Git не добавлять. Владелец не планирует публиковать документы сертификации.

Пока оригиналы в этот каталог не перенесены. Найденные материалы в соседнем проекте и выгрузка Instagram описаны в [CONTENT.md](../../docs/CONTENT.md); наличие ссылки не означает, что файл получен или проверен.

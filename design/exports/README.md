# Подготовленные материалы

Здесь хранить макеты, производные изображения, превью и снимки проверки. Для результата указывать задачу, источник и версию. Исходники компании остаются в `design/source/`.

Утверждённого макета корпоративного сайта пока нет. Схема в чате — предварительный прототип, не окончательный дизайн. Путь и версия будущего эталона будут записаны в [DESIGN.md](../../docs/DESIGN.md).

Временные серверы, кэши и скачанные инструменты не коммитить. Состав runtime-инструментов выбирается при разработке, готового инструментария в этом каталоге нет.

## Сохранённые результаты

[structure-prototype.fragment.html](structure-prototype.fragment.html) — исходник ранее показанной схемы T03. Интерактивный фрагмент для чата, без реальной отправки и хранения заявок; не утверждённый макет. Скопирован из результата этой беседы без изменения интерфейса.

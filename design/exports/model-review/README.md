# Оценка модели биг-бэга

Дата: 18 ноября 2026 года. Исходник: [бигбег.glb](../../source/бигбег.glb). Исходник не изменялся.

## Вывод

Подходит как основа для проверки браузерной сцены и управления. Для окончательного крупного показа рекомендуется оптимизация геометрии, очистка цветовой текстуры и настройка материала ткани. Замена модели целиком по текущим данным не требуется.

Внешний вид оценён по присланному владельцем скриншоту одного ракурса и извлечённой цветовой текстуре. Файл разобран структурно, но интерактивный просмотр всех ракурсов и проверка FPS на целевых телефонах не выполнялись.

## Измеренные параметры

| Параметр | Результат |
| --- | --- |
| Формат / генератор в метаданных | GLB 2.0 / Tripo |
| Размер файла | 4 500 096 байт, около 4,5 МБ |
| Геометрия | 1 mesh, 1 primitive, 95 034 треугольника, 55 519 вершин |
| Материалы | 1 материал |
| Текстуры | Base color JPEG, roughness/metallic PNG, normal JPEG; каждая 2048 × 2048 |
| UV | Есть, значения в пределах 0–1 |
| Анимация / скелет | Нет; для вращения всей модели это не препятствие |
| Границы | Примерно 87,22 × 99,93 × 84,07 единицы; низ на Y=0, центр высоты около Y=49,96 |
| Основная проверка геометрии | Индексы допустимы, координаты конечные; после сварки совпадающих позиций с округлением до 5 знаков — 0 граничных/неманифолдных рёбер и 0 схлопнутых треугольников |

Проверка рёбер не исключает самопересечений и всех визуальных дефектов. Полный отчёт — [bigbag-inspection.json](bigbag-inspection.json).

## Внешний вид

- Силуэт узнаваем: наполненный квадратный биг-бэг, четыре подъёмные петли и верхняя горловина.
- На присланном ракурсе заметны неровные границы синего цвета и белые пятна на стропах. [Цветовая текстура](basecolor.jpg) подтверждает наличие неоднородностей окраски; их стоит очистить.
- Поверхность выглядит довольно глянцевой/пластиковой. Окончательное впечатление зависит также от света в просмотрщике; материал ткани необходимо проверить под освещением будущей сцены.
- Корпус близок к жёсткому кубу. Для общего небольшого блока это допустимо; при крупном показе можно слегка усилить естественную выпуклость и складки.
- На текстуре нет фирменной маркировки Диканшы. UV позволяет подготовить брендированную текстуру, но текущая нарезка не является обещанием простого нанесения наклейки без проверки.

## Предлагаемые доработки

1. Создать отдельную облегченную версию; начальная цель 10–20 тысяч треугольников при сохранении силуэта и ручек, окончательное число по визуальной проверке. Четыре исходных экземпляра дают 380 136 треугольников до дополнительных элементов сцены. Это не результат замера FPS и не означает автоматическую непригодность исходника.
2. Очистить стропы/границы цвета, настроить менее пластиковый материал, сохранить фактуру ткани.
3. Привести масштаб к согласованным размерам и перенести центр вращения к центру мешка; текущий origin расположен по высоте у основания. Исходные 100 единиц не принимать за фактическую высоту настоящего мешка.
4. Для взаимодействий использовать простую отдельную форму столкновений; визуальную сетку из 95 тысяч треугольников не требуется делать физическим телом целиком. Конкретный физический движок ещё не выбран.
5. Отдельно проверить вид сверху/сзади/снизу, отверстия ручек и брендирование; затем браузерную загрузку и управление на компьютере/телефоне. Оригинал хранить неизменным.

Ни оптимизация, ни ретушь, ни реализация физики в этой оценке не выполнялись.

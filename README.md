# Диканшы — корпоративный сайт

Рабочий проект редизайна основного dikanshy.kz: корпоративная витрина на русском, казахском и английском. Компания, органика, экспорт, переработка, ассортимент и обращения; комбикорма ведут в отдельный `/feed`, самостоятельный `/retail` — позднее.

## Текущее состояние

Подготовлены бриф, предложение структуры, предварительная интерактивная схема в чате и список задач. Структура и дизайн ещё не утверждены. Референсы не собраны, стек не выбран, рабочего приложения пока нет.

Порядок: **задачи → структура → сбор и обсуждение референсов → контент → дизайн → разработка → проверка → запуск**.

Ближайшие задачи: T04 и T07–T12. Список работ — в [реестре](planning/TASKS.md), этапы — в [плане](planning/PLAN.md).

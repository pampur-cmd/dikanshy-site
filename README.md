# Диканшы — корпоративный сайт

Планирование редизайна основного сайта dikanshy.kz.

Корпоративная витрина на русском, казахском и английском: компания, органическое направление, экспорт, переработка, ассортимент и контакты. Комбикорма представлены переходом в отдельный `/feed`; самостоятельный `/retail` запланирован позднее.

## Порядок работы

Задачи → согласование структуры → сбор и обсуждение референсов → контент → дизайн → разработка → проверка → запуск.

Сейчас подготовлены бриф, предложение структуры, предварительная интерактивная схема в чате и список задач. Структура и макеты не утверждены, разработка рабочего сайта не начата. Ближайший этап — обсуждение структуры и подбор референсов.

Дамп базы, копия Joomla, локальные инструкции и скрипты переноса не входят в репозиторий. Они остаются отдельно в рабочей папке. Секреты и персональные данные обращений в Git не сохраняются.

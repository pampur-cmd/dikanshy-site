## Предложения, которые не считаются согласованными

- Пять основных страниц, точные адреса с `/ru`, `/kk`, `/en`, расположение блоков и возврат из feed — T04.
- Имя необязательно; для общего обращения нужен товар или сообщение; тип партии один на обращение; скрытие объёма сохраняет заполненное значение — T05.
- Отдельный бот, периоды сегодня/7/30 дней, порог 5 заявок, XLSX с листами «Заявки»/«Товары» — T06. Пользователь подтвердил сценарий, но не эти числовые и технические детали.
- Подборка Instagram с локальными медиа вместо автоматической ленты — T17.
- Возможное повторное использование архитектурных подходов feed — T28; стек, пакеты и версии не утверждены.

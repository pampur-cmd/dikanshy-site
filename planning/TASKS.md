# Задачи редизайна dikanshy.kz

Обновлено: 17 ноября 2026 года.

Источники: [бриф](../REDESIGN_PLAN.md), [структура и сценарии](SITE_STRUCTURE.md), локальный `MIGRATION_PLAN.md` (хранится отдельно, в Git не публикуется).

## Порядок работы

**Задачи → уточнение структуры → сбор и обсуждение референсов → контент → дизайн → разработка → проверка → запуск.**

Сейчас оформлен список задач. Следующий рабочий этап — согласование структуры и сбор референсов. До завершения этапа референсов не разрабатываем финальный визуальный дизайн. До согласования макетов не начинаем реализацию рабочего сайта. Уже показанная схема — предварительный прототип для обсуждения, не утверждённый дизайн.

Самостоятельный retail, переделка feed и автоматическая синхронизация Instagram не входят в первую версию. Рабочее размещение координируется с существующим планом миграции, без повторного выполнения уже проверенных работ.

## Как вести задачи

- `Готово` — указанный результат существует и проверен в пределах задачи; это не заменяет согласование владельцем, если оно выделено отдельно.
- `На обсуждении` — предложение подготовлено, решение ещё не принято.
- `Запланировано` — работа ещё не выполнена; зависимости указаны в строке.
- `В работе` — задача действительно выполняется; отмечать при начале работы.
- `Отложено` — будущая работа вне первой версии.

При закрытии задачи добавлять ссылку на результат и краткую запись о проверке. Не отмечать реализацию готовой по одному макету или описанию. Зависимость от незавершённой задачи не означает внешний блокер. Сроки и оценки пока не назначены.
